Case 01TanikaLaya
Thesis / In developmentDecision support

Making complex indicators
easier to understand.

TanikaLaya is a non-clinical, human-in-the-loop decision-support system using Mamdani fuzzy inference to process assessment indicators and produce explainable indicator concern levels for expert review.

Assessment
indicators→Fuzzy
inference→Expert
review
  • Python
  • Fuzzy logic
  • Mamdani inference
  • Explainability
Inside the project +

The focus is explainable decision support: outputs are indicator concern levels for a human expert to review. This thesis is in development; it is not a diagnostic tool or a clinical risk predictor.
